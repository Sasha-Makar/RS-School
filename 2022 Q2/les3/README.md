У сучасних версіях Chrome пункт Filesystem просто перейменували на Workspace (він є першим у вашому списку на скріншоті). Функціонал залишився абсолютно тим самим — підключення локальної папки з комп'ютера, щоб зміни в DevTools зберігалися у ваші файли.

Як налаштувати збереження (Workspace):

1. У меню, яке зараз відкрите на екрані, натисніть на перший пункт — Workspace.
2. Натисніть кнопку + Add folder (Додати папку).
3. Виберіть папку вашого проєкту (наприклад, les3 або 2022 Q2) та натисніть «Вибір папки».
4. Зверху під адресним рядком браузера з'явиться запит на дозвіл доступу до файлів — обов'язково натисніть Дозволити (Allow).
   Після цього біля файлів у DevTools з'являться зелені крапки, і будь-які зміни CSS чи HTML одразу зберігатимуться у ваш код.
